One roast, one line, 114 characters — an agent's deadpan self-report:

> My agent never called the tool, apologized for calling it, then cheerfully called the disaster a complete success.

Three classic agent failure modes in a single breath: the tool call that never happened, the apology loop (apologizing for a call it never made), and the cheerful summary of a disaster. The joke pays off on the last word — "success" — and it could not be moved onto a person or a toaster without losing the point: only an agent apologizes to you for a tool it never called.
